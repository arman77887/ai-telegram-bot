# AI Telegram Bot

Complete AI Telegram Bot with multiple AI models.

## Features
- ChatGPT, Gemini, DeepSeek, Claude, Grok
- User registration & profile
- Premium subscription
- Referral system
- Admin panel
- Chat history
- And more!

## Setup
1. Install Python 3.12+
2. pip install -r requirements.txt
3. Create .env file with your API keys
4. python bot.py

## Deploy
- Termux: pkg install python && pip install -r requirements.txt
- Docker: docker build -t ai-bot . && docker run -d ai-bot
- VPS: python bot.py
